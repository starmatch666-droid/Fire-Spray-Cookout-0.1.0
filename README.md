# 火喷：高速野炊

将 SG-225IE 高燃破裂者（火喷）与 SG-451 野炊的有利弹丸属性取较高值。

- 每枪弹丸：12 → 20
- 单弹丸伤害：保持火喷的 20
- 单弹丸耐久伤害：保持火喷的 10
- 硬直力：10 → 35
- 推动力：10 → 20
- 拆迁力：保持 10
- 燃烧效果与穿甲：保持火喷原值
- 弹匣、装填方式、300 RPM 射速、散布完全不变
- 不修改泵动动作或野炊武器组件

## 依赖

**只需要 Bingus Shared Loader v15 及以上**（或兼容的新版本）。

无需其他前置，下载即用。

## 安装

使用 Arsenal / HD2 Mod Manager 导入 ZIP，启用共享 Loader 后部署，彻底退出游戏再重新启动。Loader 放到列表最后（若开启「首个 mod 优先」则放最前）。

## 版本与适配

- 适配游戏构建 **25327279**。
- 运行时受保护写入与回读已通过，用户已实测确认生效。
- 硬直、推动和弹丸密度的实战手感仍建议自行复核。

## 日志

```
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\FireSprayCookout.log
```

写入成功会记录 `applied_template_gameplay_unverified`；数据不匹配时记录 `*_not_write` 并**拒绝写入**，不会强行覆盖。

## 注意

- 内存模组属**客户端运行时改动**：只在本次游戏会话内生效，退出游戏即恢复原状。
- 联机表现可能与队友不一致，并存在**反作弊风险**。建议仅在知情固定队环境中使用。
- 卸载：用管理器禁用本包并重新部署；手动安装需保持 `patch_N` 编号连续，**不要直接删除中间编号的文件**。
